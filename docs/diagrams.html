2. Data Flow — Vòng đời tin nhắn

Cách một tin nhắn Zalo đi từ realtime WebSocket đến frontend hiển thị, lưu DB, và forward cho Dify bot.

sequenceDiagram participant Z as 🔗 Zalo WS participant L as 👂 GoldListener participant N as 🔄 Normalizer participant M as 📥 appendMsg() participant Cache as 🗂️ In-Memory Map participant DB as 🐘 PostgreSQL participant D as 🤖 DifyBotExecutor participant WS as 📶 WebSocket Server participant F as 💬 React Frontend Z->>L: message event (raw) L->>N: normalize (text, kind, attachments, reactions) N-->>L: GoldConversationMessage L->>M: appendConversationMessage(msg) M->>M: dedup check (seenMessageKeys + 15s window) alt is duplicate M-->>L: ignored else new message M->>Cache: push + sort M->>DB: replaceConversationMessagesByAccount() M->>D: onConversationMessage() callback D-->>D: matchesFilter? POST webhook → Dify M->>WS: broadcast to listeners WS->>F: realtime update (Zustand store) end Note over L,Z: Listener auto-retry on error
5 close in 10min → needsRelogin
Watchdog 30s: restart / relogin Note over D: Bot filter: enabled + direction
+ receive_groups whitelist
→ if match: POST to webhook URL
Luồng: Zalo WS → Listener → Normalize → Append (dedup) → Cache + DB + WebSocket broadcast → Frontend. Bot Executor nhận message qua onConversationMessage callback, nếu filter match thì POST webhook đến Dify Platform.
