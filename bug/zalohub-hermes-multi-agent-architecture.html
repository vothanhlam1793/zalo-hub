ZaloHub + Hermes — Multi-Agent Architecture

1 Dify Bot = 1 Profile = 1 Agent — mỗi agent phụ trách group riêng, có skill/memory/tool riêng

1 Dify Bot = 1 Agent

  • • Mỗi agent có 1 Dify Bot riêng trong ZaloHub
  • • Receive whitelist: bot chỉ trigger webhook cho group được chỉ định
  • • Send whitelist: bot chỉ được reply vào group được phép
  • • 1 token = 1 agent — không trộn lẫn

Profile = Adapter + Skills

  • • Mỗi profile chạy 1 ZaloHub adapter port riêng
  • • Skills chuyên biệt: ngochoang-agent, creta-sheet...
  • • Memory + state.db riêng — không đụng độ
  • • Thêm agent = tạo bot + profile, không sửa code

Filter sớm = Giảm noise

  • • ZaloHub filter whitelist TRƯỚC khi gọi webhook
  • • 100 group → webhook chỉ bắn cho 1-5 group whitelist
  • • Hermes không phải check allowed_groups nữa
  • • Không thể gửi nhầm group (send whitelist chặn)
